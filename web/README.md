# Consulta de endereços — ViaCEP

SPA em React que consulta a [ViaCEP](https://viacep.com.br/) por CEP ou por endereço.

```bash
npm install
npm run dev
```

Build de produção: `npm run build` e `npm run preview`.

A URL padrão da API é `https://viacep.com.br`. Para sobrescrever, use a variável `VITE_VIACEP_BASE_URL`.
